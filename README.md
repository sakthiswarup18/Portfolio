# Portfolio — Sakthi Swarup

A single-page portfolio website showcasing data analytics work, interactive dashboards, and professional experience.

## Structure

```
Portfolio/
├── index.html                     # Main portfolio page
├── sakthi-portfolio.html          # Alternative portfolio layout
├── assets/
│   ├── css/
│   │   └── styles.css            # Main stylesheet
│   ├── js/
│   │   ├── script.js             # Portfolio behaviors (theme, menu, filters, scrollspy)
│   │   ├── data.js               # Synthetic data for dashboards
│   │   └── dashboards.js         # Interactive dashboard rendering
│   ├── img/
│   │   ├── favicon.svg
│   │   ├── sakthi-headshot.jpg
│   │   ├── sakthi-headshot-500.jpg
│   │   └── impact-award.png
│   └── pdf/
│       ├── Sakthi-Swarup-Resume.pdf
│       ├── cert-*.pdf            # Certificates (9 files)
│       ├── award-*.pdf           # Awards (3 files)
│       └── iot-cybersecurity-paper.pdf
└── README.md                      # This file
```

## Features

- **Responsive design** with mobile-first breakpoints
- **Light/dark theme** with localStorage persistence
- **Interactive dashboards** (3 panels):
  - Hospital operations analytics
  - Data job salary trends
  - Crypto forecast backtesting
- **Project filtering** by category with accessibility support
- **Scrollspy navigation** that highlights current section
- **Print-optimized** styles for PDF generation

## Tech Stack

- Vanilla JavaScript (no frameworks)
- Hand-written SVG visualizations
- CSS custom properties for theming
- Semantic HTML with ARIA labels

## Dashboard Data

All dashboard data is **synthetic** and deterministic, generated by `data.js` using seeded pseudo-random number generators. See the file's header comments for the statistical assumptions behind each dataset.

## Development

Open `index.html` or `sakthi-portfolio.html` directly in a browser. No build step required.

## Deployment

The site is deployed to Netlify at https://sakthiswarup.netlify.app/

All asset paths are relative, so the site works from any hosting location or locally via `file://`.
